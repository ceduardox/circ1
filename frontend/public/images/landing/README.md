# Imágenes de la landing

Coloca aquí las imágenes que quieras utilizar en la página pública.

Nombres sugeridos:

- `hero.webp` — imagen principal de portada
- `metodo.webp` — sección del método
- `comunidad.webp` — comunidad o acompañamiento
- `transformacion.webp` — crecimiento personal y de negocio

Estas imágenes estarán disponibles en la aplicación mediante rutas como:

`/images/landing/hero.webp`
